# Nav
一个简单的网址导航站点

## 主要功能
- [x] 单个html文件实现网址书签导航功能
- [x] 书签分类，卡片式展示
- [x] 书签卡片悬浮动画
- [x] 书签标题的首个字符作为图标
- [x] 支持书签搜索
- [x] 滚动页面时显示一键返回顶部按钮
- [x] 支持亮色/暗色模式切换
- [x] 响应式设计，适配桌面端和移动端等不同设备
